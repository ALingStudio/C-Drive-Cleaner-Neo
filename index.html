常见问题

关于 C Drive Cleaner neo，你可能想知道的

C Drive Cleaner neo 是免费的吗？
完全免费。采用 MIT 开源协议，源代码完整公开，可自由查看、构建与分发，没有任何功能限制或付费解锁。
需要安装吗？
不需要安装。下载后为单文件便携版（仅 8.8 MB），双击即可运行。首次运行时系统会提示管理员权限，确认即可。
支持哪些 Windows 版本？
支持 Windows 10 和 Windows 11 的 64 位系统。基于 Go + Wails v2 构建，调用系统原生 WebView2 渲染界面。
安全吗？会误删文件吗？
清理命令逐字取自经过广泛验证的原版 v2.9 bat 脚本，并通过 SHA-256 校验完整性。危险操作独立分区并红色警示，建议首次使用时选择「一键快速清理」中的安全项。
为什么需要管理员权限？
C 盘的系统垃圾文件（如 Windows 更新缓存、临时文件等）位于受保护的系统目录，需要管理员权限才能访问和清理。neo 完全离线运行，不会上传任何数据。
和旧版（Electron 版）有什么区别？
neo 用 Go + Wails 完全重写，单文件仅 8.8 MB（旧版约 100+ MB），启动更快、内存占用更低，使用原生 WebView2 而非捆绑 Chromium。清理引擎行为与原版完全一致。
